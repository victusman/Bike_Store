# Bike_Store - Módulos Productos y Usuarios

Instrucciones rápidas:

1. Copie `bike_store.sql` y ejecútelo en MySQL Workbench para crear la base de datos y tablas.
2. Coloque este proyecto en `c:/xampp/htdocs/Bike-store` (ya está en esa ruta).
3. Asegúrese que Apache y MySQL estén activos en XAMPP.
4. Abra en el navegador: http://localhost/Bike-store/

Archivos creados:
- `bike_store.sql` - script SQL para crear la DB y tablas.
- `db.php` - archivo de conexión PDO.
- `index.php` - panel con enlaces a los módulos.
- `products/` - tendrá CRUD para productos.
- `users/` - tendrá CRUD para usuarios.

Siguientes pasos: crear archivos PHP para CRUD de productos y usuarios (listas, crear, editar, eliminar).
